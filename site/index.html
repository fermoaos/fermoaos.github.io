에이전트가 “완료했다”고 말하는 것을 믿지 않습니다. 지금 사고하고 검증하는 상태만 진짜입니다.

일은 끝나는 것이 아니라 흘러갑니다. 우리는 그 흐름이 한 점에 모이는 순간을 붙잡습니다.

그 점에서 사람이 이해하고, 에이전트가 실행합니다. 그것이 페르모아입니다.

AgentOS

다섯 계층이 하나의 운영체계를 이룹니다. 각 계층은 따로 도입할 수 있고, 함께 있을 때 서로를 검증합니다.

  1. 에이전트 런타임

    한 문장의 지시를 끝까지 실행하는 런타임입니다. 에이전트는 스킬로 정의되고, 무엇을 판단해 무엇을 했는지가 전부 기록에 남습니다.

  2. 계약 계층

    캠페인, 지표, 예산을 먼저 계약으로 적습니다. 정책과 승인, 롤백은 그 계약 위에서 돌기 때문에 에이전트가 무엇을 넘으면 안 되는지 사람이 먼저 압니다.

  3. 파이프라인

    룰팩으로 판정하고 증분으로 검증합니다. 바뀐 것만 다시 계산하므로 매일 돌려도 가볍고, 어제와 오늘의 차이를 그대로 보여줍니다.

  4. 모델 게이트웨이

    OpenAI 호환 단일 엔드포인트입니다. 키와 예산, 라우팅과 폴백, 토큰 미터링을 한곳에서 관리하고 모든 요청을 테이프로 남깁니다.

  5. 엣지 에이전트

    기기 안에서 의도를 추론합니다. 4비트 양자화 SDK와 연합학습으로 데이터는 기기를 떠나지 않고, 서버는 학습된 결과만 받습니다.

Agentic Operations

운영 복잡도가 높고 맥락이 중요한 업무부터 시작합니다. 다섯 영역이 같은 런타임과 계약 위에서 돕니다.

  • 회사 운영

    근로계약, 급여 마감, 4대보험, 법정 의무 판정을 자연어 한 문장으로.

  • 미디어

    네이버, 카카오, 구글, 메타 매체를 계약과 승인 아래 자율 집행.

  • 커머스

    쇼핑 의도를 거래로. 머천트 쪽에서 도는 에이전트 커머스.

  • 그로스

    D2C 재구매, 정기구독 전환, 인플루언서 공구를 에이전트가 운영.

  • 디스커버리

    AI 답변 엔진 안에서의 가시성과 인용, 추천 확률을 측정하고 조정.

역량 지도

직접 만들고 실측한 엔진 네 계열입니다. 전부 에이전트가 채팅에서 도구로 부릅니다.

  • 배정·일정 최적화

    간호사 근무표, 콜센터 배치, 리그 일정, 방 배정, 승무원 페어링, 학교 시간표, 실시간 배차. 채팅으로 조건을 말하면 제약 솔버가 표를 냅니다.

  • 비전·신호 판정

    외관 불량 검사, 무선 간섭 진단, 기기 지문, 설비 음향·진동, WiFi 재실. 수신기 9단계를 직접 구현했고 판정은 실시간입니다.

  • 문서·지식·상담

    문서 자동 인식과 입력, 고객 문의 자동응대, 사내 지식 검색. 반복 문의의 60~70% 를 에이전트가 받습니다.

  • 수요·경영 데이터

    경영 현황 대시보드, 수요예측과 발주 시뮬레이터, 영업 신호 레이더. 현황 파악이 반나절에서 조회 즉시로 줄어듭니다.

Use Cases

말로 설명하는 대신 눌러 보시면 됩니다. 일곱 계열 76개 데모가 전부 브라우저에서 돌고, 에이전트는 이것들을 도구로 부릅니다.

  • 배정·일정 최적화

    조건을 말하면 제약 솔버가 표를 냅니다. 최적을 노리기 전에 어떤 조건에서도 실행 가능한 해부터 보장합니다.

    • 간호사 근무표 편성
    • 콜센터 인력 배치
    • 리그 일정 편성

  • 문서·지식·상담

    문서를 읽고 입력하고, 문의에 답하고, 사내 지식을 인용과 함께 찾습니다. 반복 문의의 60~70%를 에이전트가 받습니다.

    • 문서 자동 인식, 입력
    • 고객 문의 자동응대
    • 사내 지식 검색

  • 수요·경영 데이터

    경영 현황, 수요예측과 발주, 영업 신호. 현황 파악이 반나절에서 조회 즉시로 줄어듭니다.

    • 경영 현황 대시보드
    • 수요예측, 발주 시뮬레이터
    • 영업 신호 레이더

  • 비전·신호 판정

    안테나에서 판단까지 직접 구현한 수신기와 비전 검사기. 판정은 실시간이고 근거는 스펙트럼과 함께 옵니다.

    • 외관 불량 검사
    • 무선 간섭 진단
    • 의료영상 도구 운용 폐루프

  • 업무 에이전트

    한 문장 지시를 분해해 위의 엔진들을 도구로 부르는 층. 판정은 코드가, 승인은 사람이 합니다.

    • 대화형 AI 오케스트레이터
    • 조합 최적화 의사결정
    • 에이전트 하네스 품질 검사

  • 모델 서빙·비용

    자체 호스팅 손익, VRAM, 양자화, 라우팅. 모델 게이트웨이가 무엇을 근거로 고르는지를 계산기로 보여줍니다.

    • LLM 자체 호스팅 계산기
    • 파인튜닝 방법 계산기
    • 멀티에이전트 라우팅 비용

  • 미디어·콘텐츠 생성

    광고 영상, 숏폼, 캐릭터, 음성. 매체 운영 에이전트가 집행할 소재를 같은 운영체계 안에서 만듭니다.

    • 이슈 연동 광고 영상 스튜디오
    • 웹 존재감 진단
    • 건축 블록아웃 폐루프

AI Fabric

폰과 가전과 로봇과 공장과 기지국을 한 회사가 다 만드는 제조사를 상정하고, 그 위에 에이전트를 얹으려면 무엇이 있어야 하는지를 25개 항목으로 설계했습니다. 특정 고객사의 요구가 아니라 우리가 스스로 세운 레퍼런스 프로그램입니다.

6개는 게이트가 도는 코드, 19개는 설계와 스캐폴드

  • A 토큰과 추론5

    모든 요청이 지나는 길목과, 그 길목이 고를 수 있는 목적지들. 나머지 여섯 묶음의 전제조건입니다.

    1 게이트 도는 코드

  • B 개인화와 프라이버시4

    개인 데이터를 서버로 올리지 않고 개인화합니다. 팔 것은 예측이 아니라 원 데이터가 나가지 않는다는 계약입니다.

    1 게이트 도는 코드

  • C 에이전트 플랫폼3

    설치 단위가 앱에서 스킬로 바뀌는 순간에 필요한 것 — 배포처, 권한 판정, 그리고 기존 자산을 옮길 경로.

  • D 신원·결제·거래4

    에이전트가 사람 대신 돈을 쓰려면 위임과 회수가 하드웨어로 보증돼야 합니다.

  • E 기업과 플릿2

    기술 난이도는 낮고 조직 난이도가 높은 묶음입니다. 기존 계약 위에 얹히는 것부터 시작합니다.

    1 게이트 도는 코드

  • F 집과 로봇2

    집은 연산 자원이자 상태 표현입니다. 로봇에서는 승인과 롤백이 편의가 아니라 안전 요구입니다.

    1 게이트 도는 코드

  • G 제조·통신·검증5

    이미 검증된 방법론이 있는 영역과, 사기 전에 값싼 기준선으로 판정하는 자(尺).

    2 게이트 도는 코드
