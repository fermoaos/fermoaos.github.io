개인정보 처리방침

이 사이트는 방문자에 대해 아무것도 수집하지 않습니다. 계정도 로그인도 분석 도구도 광고 추적도 없습니다. 아래는 그 말이 정확히 무슨 뜻인지입니다.

우리가 저장하는 것

없습니다. 이 사이트는 정적 파일로만 돌아가고, 우리가 소유한 서버나 데이터베이스가 없습니다. 방문 기록을 우리 쪽에 남기는 코드가 존재하지 않습니다.

브라우저에 남는 것

fermoa-theme 키 하나입니다. 그래프지와 칠판 중 어느 화면을 골랐는지만 담고 방문자의 브라우저 안에만 있습니다. 우리에게 전송되지 않고, 지우면 다음 방문에 시스템 설정을 따릅니다.

쿠키는 쓰지 않습니다.

문의 양식

세 단계 양식은 입력한 내용을 방문자의 메일 프로그램에 넘겨 편지 초안을 엽니다. 보내기를 누르는 것은 방문자이고, 편지는 우리 서버가 아니라 방문자가 쓰는 메일 서비스를 거쳐 도착합니다. 우리가 받는 것은 그 편지 한 통뿐입니다.

받은 편지에 담긴 내용은 그 문의에 답하는 목적으로만 씁니다. 다른 곳으로 옮기거나 광고에 쓰지 않습니다.

제3자에게 가는 요청

페이지를 열면 방문자의 브라우저가 세 곳에 직접 요청을 보냅니다. 제목과 본문 서체를 위해 Google Fonts(fonts.googleapis.com, fonts.gstatic.com)에, 한글 서체를 위해 jsDelivr(cdn.jsdelivr.net)에 갑니다. 이 요청에는 IP 주소와 브라우저 정보가 담기며 각 회사의 방침을 따릅니다.

사이트 자체는 GitHub Pages 가 호스팅합니다. 따라서 GitHub 도 접속 기록을 봅니다.

Use Cases 에 있는 데모 링크는 눌렀을 때만 다른 주소로 이동합니다. 누르지 않으면 아무 요청도 가지 않습니다.

없는 것

분석 도구, 태그 매니저, 추적 픽셀, 광고 네트워크, A/B 테스트 도구, 세션 리플레이, 채팅 위젯. 하나도 쓰지 않습니다. 이 문장은 확인할 수 있습니다 — 브라우저 개발자 도구의 네트워크 탭을 열고 이 사이트를 새로고침해 보시면 위에 적은 세 곳 말고는 나가는 요청이 없습니다.

재생 데모

홈의 에이전트 데모는 미리 녹화해 둔 실행 기록을 이 사이트 안에서 재생합니다. 입력을 받지 않고, 바깥으로 나가는 요청도 없습니다. 승인 버튼을 눌러도 그 클릭은 재생을 이어가는 것 외에 아무 데도 가지 않습니다.
