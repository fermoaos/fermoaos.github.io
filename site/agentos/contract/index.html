계약 계층

캠페인, 지표, 예산을 먼저 계약으로 적습니다. 정책과 승인, 롤백은 그 계약 위에서 돌기 때문에 에이전트가 무엇을 넘으면 안 되는지 사람이 먼저 압니다.

광고 매체마다 API 가 다르고 귀속 기준이 다릅니다. 계약 계층은 그 차이를 Campaign IR 과 Metric Contract 로 먼저 적습니다. 귀속 기준이 다르면 합계를 만들지 않고, 못 본 축은 못 봤다고 말합니다. 단일 창인 척 적는 순간 이 제품이 남에게 금지하는 오류를 우리가 저지르는 것이기 때문입니다.

에이전트에게 노출되는 것은 업무 단위 도구 12개뿐입니다. 급락 원인 조사, 채널 비교, 최적화 계획 수립, dry-run 시뮬레이션, 승인된 계획의 실행, 기록된 값으로의 롤백. 매체별 저수준 API 는 노출하지 않고, 승인 부여는 사람 전용이라 에이전트 도구 목록에 아예 없습니다.

실행은 멱등이고 사후조건을 되읽습니다. 변경 이력은 해시 체인 감사 원장에서 설명되며, 증분을 잴 수 있는지 판정한 뒤에만 pre/post 이중차분을 돌립니다.

핵심

증분
