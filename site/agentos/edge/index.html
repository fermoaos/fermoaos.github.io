엣지 에이전트

기기 안에서 의도를 추론합니다. 4비트 양자화 SDK 와 연합학습으로 데이터는 기기를 떠나지 않고, 서버는 학습된 결과만 받습니다.

SDK 는 2.2MB 입니다. 예산 5MB 의 42%. 의도 벡터화는 기기 안에서 p95 0.257ms 에 끝납니다. 원본 발화와 프로필은 전송되지 않고 가중치만 집계되며, 카나리아 7건은 전부 미검출이었습니다. 광고 요청 자체가 없습니다. 카탈로그 3,000 항목이 통째로 번들되기 때문입니다.

5MB 로 30억 파라미터 모델을 돌린다고 말하지 않습니다. 실제 구조는 두 층입니다. 상시 경로는 우리가 직접 증류한 초소형 정적 임베딩이고, OS 내장 모델이 있는 기기에서만 추론 깊이를 올립니다. 220배 작은 모델이 교사의 78%에서 87% 를 냅니다.

프라이버시 예산 ε ≤ 2.0 은 기술 값이 아니라 계약 조건입니다. 기기 인구 1만 미만인 파일럿에서는 연합학습을 끄고 원문 전송 0 만 약속합니다. 1만 이상에서 학습을 켜고 캠페인 ε 을 공개합니다.
