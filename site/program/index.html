디바이스 제조사를 위한 25개 항목

폰과 가전과 로봇과 공장과 기지국을 한 회사가 다 만드는 제조사를 상정하고, 그 위에 에이전트를 얹으려면 무엇이 있어야 하는지를 25개 항목으로 설계했습니다. 특정 고객사의 요구가 아니라 우리가 스스로 세운 레퍼런스 프로그램입니다.

25개 중 6개는 게이트가 도는 코드까지 갔고, 19개는 설계와 스캐폴드 단계입니다. 어느 쪽인지 항목마다 적어 두었습니다.

A. 토큰과 추론B. 개인화와 프라이버시C. 에이전트 플랫폼D. 신원·결제·거래E. 기업과 플릿F. 집과 로봇G. 제조·통신·검증

A 토큰과 추론 5

모든 요청이 지나는 길목과, 그 길목이 고를 수 있는 목적지들. 나머지 여섯 묶음의 전제조건입니다.

  • 01게이트 도는 코드

    AI 라우터 — 토큰 통제면

    모델이 아니라 통제면입니다. 모든 요청이 지나는 길목을 소유하는 것이 나머지 24개의 전제조건입니다.

    OpenAI 호환 단일 내부 엔드포인트. 요청마다 온디바이스·사내 클라우드·외부 프런티어를 SLO 와 프라이버시 등급으로 판정하고, 실패하면 폴백하며, 토큰을 기능·조직 단위로 계량합니다.

    기능·조직 귀속 원장과 반사실 원가, 게이트 G1~G7 이 exit 0/1 로 판정합니다. 요청 스키마 확장과 세 경로 배선까지 완료, e2e 22개 전부 통과.

  • 02설계·스캐폴드

    스킬 증류 공장

    큰 모델이 반복하는 좁은 일을 찾아 작은 모델로 내리는 일을, 사람이 아니라 파이프라인이 합니다.

    라우터 원장에서 반복 작업을 군집화하고, 교사 트레이스를 모아 합성 데이터를 만들고, 증류·게이트·양자화·기기 벤치·배포까지 갑니다. 각 단계의 통과 여부는 사람 판단이 아니라 게이트가 정합니다.

  • 03설계·스캐폴드

    모델 최적화 플랫폼

    양자화 연구자와 경쟁하면 집니다. 그 연구들을 골라 쓰는 층이 비어 있습니다.

    개발자는 목표만 줍니다 — 정확도 하락 1% 이내, 지연 50ms 이내, 메모리 500MB 이내, 타깃은 모바일 SoC 두 종. 플랫폼이 격자를 돌려 최적점을 고릅니다.

  • 04설계·스캐폴드

    디바이스 우선 추론 SDK

    온디바이스로 떨어지는 만큼 원가가 0인 추론은, 하이퍼스케일러가 이길 수 없는 단가입니다.

    한 줄로 요청합니다 — 작업, 프라이버시 등급, 지연 상한, 비용 상한. 라우터가 기기 능력을 보고 온디바이스·엣지·클라우드를 고르고, 청구는 실제로 클라우드로 나간 것만.

  • 05설계·스캐폴드

    통신 엣지 토큰 거점

    통신사 엣지를 콘텐츠 거점이 아니라 토큰 거점으로 만듭니다.

    통신사 MEC 에 추론 런타임을 올려 온디바이스와 클라우드 사이의 중간 티어를 만듭니다. 라우터의 세 번째 목적지가 되고, 통신사에게는 새 매출원이 됩니다.

B 개인화와 프라이버시 4

개인 데이터를 서버로 올리지 않고 개인화합니다. 팔 것은 예측이 아니라 원 데이터가 나가지 않는다는 계약입니다.

  • 06설계·스캐폴드

    프라이빗 오디언스 엔진

    구매 확률을 예측하겠다고 하면 이미 한다는 답이 돌아옵니다. 팔아야 할 것은 원 데이터가 나가지 않는다는 계약입니다.

    앱 사용·검색 맥락·구매·시간·장소 범주를 기기 안 소형 사용자 모델이 벡터화하고, 서버로는 거친 세그먼트 토큰과 신뢰구간과 만료시각만 보냅니다. 개별 이벤트도, 사용자별 광고 요청도 존재하지 않습니다.

  • 07설계·스캐폴드

    연합 어트리뷰션

    타게팅만 프라이버시로 옮기면 광고주는 사지 않습니다. 측정이 같이 옮겨가야 합니다.

    차별점은 조인이 일어나는 위치입니다. 클린룸은 서버에서 만나고, 이것은 기기 안에서 노출과 전환이 만난 뒤 집계만 올라갑니다. TV 노출과 모바일 전환을 한 가구 안에서 잇는 일도 로컬에서만 합니다.

  • 08게이트 도는 코드

    개인 AI 기억

    에이전트 시대에 가장 방어 가능한 자산입니다. 그리고 폰 밖까지 확장할 수 있는 회사는 드뭅니다.

    폰·워치·PC·TV·차·가전·로봇이 같은 개인 기억 그래프에 씁니다. 저장은 하드웨어 보안 계층이 암호화하고 소유는 사용자에게 있습니다. 외부 에이전트는 기억을 복사해 가는 대신 스코프된 질문을 보내고 답만 받습니다.

    소유권 7축(스코프·카나리·회수·삭제·내보내기·평면분리·감사) 게이트 전부 통과. 게이트 자신을 겨냥한 돌연변이 3종 — 접두 일치, 대소문자 무시, 패턴 일치로 스코프를 우회하는 변형 — 을 모두 잡는지까지 검증합니다.

  • 09설계·스캐폴드

    개인 어댑터 배포

    모든 사용자에게 같은 모델을 주지 않습니다. 베이스에 개인 어댑터를 더합니다.

    개인 데이터는 나가지 않고 어댑터만 기기에서 학습·병합됩니다. 서버는 어댑터 자체도 보지 않습니다. 기기를 바꾸면 어댑터가 암호화된 채로 따라갑니다.

C 에이전트 플랫폼 3

설치 단위가 앱에서 스킬로 바뀌는 순간에 필요한 것 — 배포처, 권한 판정, 그리고 기존 자산을 옮길 경로.

  • 10설계·스캐폴드

    에이전트·스킬 스토어

    설치 단위가 앱에서 스킬로 바뀌는 순간의 스토어입니다. 길게 보면 라우터보다 큰 사업이 될 수 있습니다.

    스킬·툴·워크플로·모델 어댑터를 배포하는 레지스트리. 서명과 권한 스코프를 하드웨어 보안 계층이 보증하고, 권한은 앱처럼 사용자에게 보입니다. 과금은 호출량 기반, 품질은 회귀 게이트가 판정합니다.

  • 11설계·스캐폴드

    에이전트 실행 거버넌스

    이 AI 가 누구 권한으로 이 행동을 했는가에 답하지 못하면, 에이전트는 첫 사고에서 멈춥니다.

    동작을 중간표현으로 받아 위험도를 분류하고 자동실행·승인요구·거부를 코드가 판정합니다. 승인은 계획 id 에 묶여 계획이 바뀌면 옛 승인이 자동으로 무효가 되고, 거부는 승인으로도 열리지 않습니다. 모든 실행은 변조 탐지가 되는 원장에 남고 롤백 경로를 갖습니다.

  • 12설계·스캐폴드

    레거시 앱을 에이전트로

    스토어의 공급 문제를 푸는 열쇠입니다. 기존 API 와 앱 수십만 개를 새로 만들 수는 없습니다.

    기존 인터페이스를 입력받아 스킬 매니페스트·권한 선언·툴 스키마·평가셋·UI 카드를 자동 생성하고, 사람은 검토만 합니다. 스토어의 초기 카탈로그가 여기서 나옵니다.

D 신원·결제·거래 4

에이전트가 사람 대신 돈을 쓰려면 위임과 회수가 하드웨어로 보증돼야 합니다.

  • 13설계·스캐폴드

    프레즌스 신원

    얼굴 하나에 의존하는 인증을 기기·웨어러블·근접·행동·암호 신원의 결합으로 바꿉니다.

    1단계는 기존 결제 단말 그대로 지갑을 열지 않고, 2단계는 워치와 링을 인증 요소로 쓰고, 3단계는 초광대역 무선으로 계산대 앞의 존재를 확인합니다. 핵심은 그 무선으로 결제 데이터를 보내지 않는다는 것입니다 — 존재 확인 채널일 뿐, 결제는 기존 레일을 탑니다.

  • 14설계·스캐폴드

    에이전트 위임 결제

    중국은 2026년 상반기에만 다섯 종을 띄웠고 한국은 아직 없습니다.

    에이전트에게 한도·기간·가맹점·카테고리가 제한된 결제 권한을 위임하는 레일. 위임 증서는 하드웨어가 보증하고, 사용자는 언제든 회수하며, 모든 사용은 원장에 남습니다. 이 순간 지갑은 지갑이 아니라 신뢰 인프라가 됩니다.

  • 15설계·스캐폴드

    트러스트 에이전트

    25개 중 실행 가능성이 가장 높습니다. 두 기능이 이미 다 있고 사이를 잇는 선만 없습니다.

    통화 위험 점수가 높은 상태에서 일어나는 송금과 결제에 단계적 마찰을 넣습니다 — 경고, 지연, 추가 인증, 가족 알림. 판정은 온디바이스에서만 하고 통화 내용은 나가지 않습니다.

  • 16설계·스캐폴드

    에이전틱 커머스 네트워크

    검색광고 회사가 아니기 때문에 오히려 거래 계층을 노릴 수 있습니다.

    사용자의 제약 — 예산·기한·조건 — 을 에이전트가 받아 판매자 에이전트들과 비교하고 결제까지 갑니다. 자리는 어느 쇼핑몰이 이기느냐가 아니라, 거래가 통과하는 레일입니다.

E 기업과 플릿 2

기술 난이도는 낮고 조직 난이도가 높은 묶음입니다. 기존 계약 위에 얹히는 것부터 시작합니다.

  • 17게이트 도는 코드

    기업 프라이빗 AI

    기술 난이도는 낮고 조직 난이도가 높습니다. 초기 실현성을 최상위로 두면 과대평가입니다.

    업무용 단말에서 보안 계층을 거쳐 AI 게이트웨이로, 다시 사내 사설 AI — 온프렘 GPU 또는 지정 클라우드 — 로 갑니다. 기업이 모델 라우팅과 정책과 감사를 직접 설정합니다.

    사내 GPU 엔드포인트로 실제 추론하는 최소 RAG 와 판정 게이트 여섯 개, 그리고 그 게이트들을 검사하는 게이트까지 라이브 실행으로 전부 통과했습니다.

  • 18설계·스캐폴드

    단말 플릿 자율 운영

    기존 계약 위에 새 계약 없이 얹히는 몇 안 되는 항목입니다. 사내 승인이 가장 쉽습니다.

    "지난주부터 배터리 소모가 18% 늘었다"에 에이전트가 답합니다 — 원격측정 분석, 특정 앱 버전 발견, 영향 단말 식별, 정책 생성, 단계적 배포. 기기 관리가 자율 운영으로 바뀝니다. 배포는 항상 승인 게이트를 지납니다.

F 집과 로봇 2

집은 연산 자원이자 상태 표현입니다. 로봇에서는 승인과 롤백이 편의가 아니라 안전 요구입니다.

  • 19설계·스캐폴드

    크로스디바이스 컴퓨트 패브릭

    집은 연산 자원이자 상태 표현입니다. 둘은 같은 문제의 앞뒷면이라 하나로 묶습니다.

    프라이버시·지연·배터리·발열을 보고 스케줄러가 추론 위치를 정합니다. 그리고 기기 원격측정에서 공간 구조와 생활 패턴을 추론해, 에이전트가 기기를 하나씩 호출하는 대신 목표를 선언하게 합니다.

  • 20게이트 도는 코드

    로봇 스킬 OS

    모터 제어가 아니라 제어면과 데이터 폐루프입니다. 그리고 제조사 자신이 첫 고객입니다.

    제어면은 모델 서빙·미션 플래너·스킬 레지스트리·원격측정·플릿·평가·배포. 데이터 폐루프는 실패 에피소드 포착, 자동 분류, 시뮬레이션 재생, 합성 변형, 재학습, 평가, 배포. 로봇에서는 승인과 롤백이 안전 요구입니다.

    물리 안전 범위 6축 게이트가 판정으로 돌아갑니다. 다만 합성 픽스처 위에서만 검증했고 실 로봇·시뮬레이터 연동은 아직 없습니다.

G 제조·통신·검증 5

이미 검증된 방법론이 있는 영역과, 사기 전에 값싼 기준선으로 판정하는 자(尺).

  • 21게이트 도는 코드

    제조·현장 배정 엔진

    세계적 규모로 제조를 하면서도 배정과 편성은 여전히 사람이 스프레드시트로 짭니다. 검증된 방법론이 있는 몇 안 되는 항목입니다.

    제약 프로그래밍 기반 배정·편성 엔진. 법정 휴게·자격·설비 호환 같은 하드 제약은 게이트로, 희망 근무·연속성 같은 소프트 선호는 목적함수로 분리합니다. 결원 재편성은 처음부터 다시 짜지 않고 변경 최소화를 목적에 넣습니다.

    공개 간호사 근무표 벤치마크 8개 인스턴스를 실측했고, 격차·실현가능성·재현성·시간예산·기준선 다섯 축이 exit code 로 판정합니다. 산출물은 스케줄러이기 전에 자(尺)입니다.

  • 22설계·스캐폴드

    RF 지문과 무선망 폐루프

    네트워크 장비를 파는 회사인데 무선 물리계층 AI 자산이 제안에서 통째로 빠져 있었습니다.

    두 축입니다. 통신 축은 RF 지문과 변조 분류와 간섭 분리를 개방형 무선망 제어 앱으로 올리고 폐루프로 효과를 측정합니다. 제조 축은 같은 신호처리 스택으로 설비의 RF 이상을 탐지합니다. 같은 코드가 두 사업부에 팔립니다.

  • 23게이트 도는 코드

    AI 조달 검증 게이트

    AI 를 사기 전에, 일주일 만든 것을 이기는지 코드가 판정합니다. 25개 중 가장 싸게 시작하고 가장 빨리 돈을 아낍니다.

    도입 대상 과제마다 값싼 기준선 — 규칙, 통계, 동시등장표 — 을 자동으로 세우고, 벤더 모델을 같은 자로 잽니다. 이기지 못하면 도입하지 않습니다. 판정은 사람 의견이 아니라 게이트의 exit code 입니다.

    일곱 축이 전부 구현됐습니다 — 기준선 유효성, 같은 자, 통계적 유의, 헤드룸, 주장 커버리지, 결정론, 예산 정직성. 게이트 자기검사 14개와 테스트 24개가 통과합니다.

  • 24설계·스캐폴드

    비전 이벤트 원장

    영상 AI 의 문제는 정확도가 아니라 원가입니다. 값싼 프리필터와 콘텐츠당 1회 상각이 그 답입니다.

    두 단입니다. 1단은 CPU 프리필터로 대부분을 버리고, 통과분만 비전 언어 모델에 넣습니다. 결과는 이벤트 원장에 적재해 콘텐츠당 한 번만 분석하고 사용자별로는 재정렬만 합니다. 비용이 사용자 수가 아니라 콘텐츠 수에 비례합니다.

  • 25설계·스캐폴드

    모델 안전 계측

    여러 모델을 함께 쓰는 체제에서, 각 모델이 무엇을 거부하고 그 대가로 무엇을 잃었는지 재는 도구가 없습니다.

    거부 표현의 인과 기하를 측정합니다. 헤드라인 지표는 거부율이 아니라 능력 변화량과 분포 발산과 개입 파라미터 수와 인과 상호작용 그래프입니다. 안전이 능력을 얼마나 깎았는지를 분리해서 냅니다.
