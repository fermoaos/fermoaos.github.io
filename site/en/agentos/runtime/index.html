AgentOS

Agent runtime

A runtime that carries a one-sentence instruction through to the end. Agents are defined as skills, and everything they judged and did stays on the record.

The first rule of the runtime is that the model does not calculate. Amounts, taxes and time are produced by pure functions; the agent explains the result. Money is decimal, not floating point, and a payroll month is a different type from a clock-in timestamp. These constraints are held by the compiler and CI, not by a document.

Register one operation and a screen, an API route and an agent tool appear together. Forget to register and the build fails. What a person sees and what an agent uses cannot drift apart.

Every calculation leaves its evidence in an append-only hash chain. That means it can be reproduced, and it has a price: a tenant with evidence can no longer be deleted. Irreversible steps are opened by a person with an approval token.
