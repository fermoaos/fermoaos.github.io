Nurse roster scheduling

State the constraints and a constraint solver returns the table. Call-center staffing, league fixtures, room assignment, crew pairing, timetables and dispatch run on the same engine.

Rosters take days of a person's time and someone is still unhappy. Statutory rest, skill mix, personal preference and consecutive-night limits are written as a CP-SAT model and measured on public nurse rostering benchmarks.

The literature review is recorded honestly: attempts to solve rostering with deep learning have not yet beaten constraint solvers. So we sell the solver, and use the model only to transcribe constraints and explain results.

Say in chat that next month is three shifts and the two new hires must not share a team; the agent turns it into constraints and calls the solver. The table is distributed only after a person reviews and approves it.
