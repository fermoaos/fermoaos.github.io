## 1. 통합 명제

> **포트폴리오는 역량 재고, 2i 는 실측 사례, Fermoa 는 그 전부를 채팅 하나로 파는 운영체계.**

사용자 지시: "통신, 스케줄링 등 뭔 걸 할 수 있고, 챗봇 기반 서비스가 가능해졌다." 즉 Fermoa 의 판매 단위는
"모델"이나 "컨설팅"이 아니라 **에이전트가 우리 엔진(통신·스케줄링·비전·수요·문서·스토리지)을 도구로 부르는 대화 서비스**다.
계산은 결정론 엔진, 판단 설명은 에이전트, 비가역은 승인 게이트 — 이미 5계층이 그 계약이다.

## 3. 배선 (이 커밋에서 실제로 한 것)

1. `content/pages.json` 에 `atlas`(역량 지도 7계열, KO/EN, 외부 링크) 추가.
2. `build_pages.py` 가 홈 KO/EN 의 `<!-- atlas:start/end -->` 마커 사이에 **역량 지도 섹션을 생성**(손편집 금지).
3. 유즈케이스 +3: 무선 간섭 진단(통신) · 간호사 근무표 편성(배정) · 스토리지 내구성 진단(인프라) — 상세 페이지 KO/EN 자동 생성, 홈 카드·푸터 링크 연결.
4. Insights 섹션에 2i 논문·실험 게시판(51편) 링크.

## 4. 신원 경계 (⛔)

Fermoa 는 회사 표면이다. 개인 포트폴리오(실명·이력서·이메일)로 **직접 링크하지 않는다** — 2i 표면 규칙과 같다.
데모 80·저장소 127 은 **숫자로만** 인용하고, 링크는 2i(회사)로 건다. 개인 포트폴리오 링크는
`pages.json.links.personal_portfolio` 가 `null` 인 동안 렌더되지 않는다(켜는 건 사용자 결정).

## 6. 정정 (2026-09-03 저녁) — 경계가 아니라 큐레이션

사용자 지시: 포트폴리오도 2i 도 본인이 혼자 만든 것이니, 가져올 때 **의미 있는 것만** 가져온다.
§4 의 "개인 포트폴리오 링크 금지"는 신원 분리 문제가 아니라 큐레이션 문제로 바뀐다. 적용:

- 역량 지도: 7계열 → **4계열**(배정·일정 / 비전·신호 / 문서·상담 / 수요·경영 데이터). 인프라·스토리지,
  마케팅·미디어(사례와 중복), 업무 에이전트(= Fermoa 자체)는 뺐다. 2i 로 나가는 링크와 사례·데모·저장소
  카운트도 뺐다 — 카운트는 2i 전체 기준이라 잘라낸 지도에서는 거짓이 된다. 배정·일정은 `cases/roster`,
  비전·신호는 `cases/interference` 로 안에서 연결된다.
- 사례: `storage`(스토리지 내구성) 제거 → 8건. AgentOS 회사 홈에서 인프라 진단은 의미가 약하다.
- 남긴 외부 링크: Insights 의 실험 기록(2i papers) 하나. 나머지는 전부 사이트 안에서 닫힌다.
- 캐릭터 이미지 배선: 히어로(테마별 칠판/그래프지 2장), AgentOS 5계층(포즈 5 = 제어 동사 5),
  Agentic Operations(상태 삼련). 케이스·Insights 의 X 박스는 실제 화면이 생길 때까지 유지.

## 7. Use Cases 를 포트폴리오 구조로 (2026-09-03 밤)

사용자 지적: "포트폴리오에서 왜 아무것도 안 가져와?" — §6 큐레이션이 지나쳐 데모가 0개였다. 정정:
`hyojunguy.github.io/assets/demos.json`(80개)을 `site/content/demos.json` 으로 가져와(인프라 4개 제외 → **76개**,
계열 7: sched 8 · doc 13 · data 8 · signal 7 · agent 6 · serve 9 · media 25) 포트폴리오 `demos.html` 의 구조
("눌러 보시면 됩니다" — 계열별 카드 + 기술 태그 + 라이브 링크)를 Fermoa 언어(헤어라인 격자 셀·형광펜 hover·칩)로
옮겼다. 홈 Use Cases = 계열 7셀(각 데모 3개 링크) + "현장에서 도는 것"(제품 케이스 8, X 박스 없이 상태 한 줄) +
전체 페이지 `usecases/index.html`(KO/EN, 76개 전부, 공개 불가 26개는 링크 없이 사유 표기). 렌더는 `build_pages.py`
(`render_usecases_home`·`usecases_page`) 가 소유하고, 포트폴리오 문장 속 "→"·" · " 는 코드가 산문으로 바꾼다
(게이트 규칙). 역량 지도의 링크 없는 셀(`.atlas-card`) 패딩 누락도 같이 고쳤다.
